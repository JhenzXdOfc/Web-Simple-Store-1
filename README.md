# 🛒 Web Simple Store 1

**Web Simple Store 1** adalah template website toko online sederhana berbasis HTML, CSS, dan JavaScript.  
Template ini cocok untuk kamu yang ingin membuat toko online kecil, katalog produk, atau sekadar portofolio jualan tanpa ribet setup backend atau database.

---

## 🎨 Fitur

- ✅ Desain minimalis dan responsif
- 🛍️ Menampilkan daftar produk beserta harga dan deskripsi
- 🔗 Tombol pemesanan/link WhatsApp
- 💻 100% statis, tidak membutuhkan hosting khusus
- 🌐 Bisa di-host di GitHub Pages

---

## 🚀 Cara Menggunakan

1. Clone atau download repository ini.
2. Edit file `index.html` dan sesuaikan:
   - Nama toko
   - Produk (gambar, nama, harga, deskripsi, link beli)
   - Kontak atau sosial media
3. Buka `index.html` di browser kamu.
4. Upload ke GitHub Pages / Netlify / hosting pribadi.

---
